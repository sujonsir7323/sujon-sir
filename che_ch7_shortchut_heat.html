রসায়নের গুরুত্বপূর্ণ নোট

জারণ সংখ্যা, একমুখী-উভয়মুখী বিক্রিয়া এবং তাপীয় পরিবর্তন

টপিক ১: জারণ সংখ্যা নির্ণয়

১. H2SO4 যৌগে S এর জারণ সংখ্যা নির্ণয়:
সমাধান:
ধরি, S এর জারণ সংখ্যা = x
আমরা জানি, H এর জারণ সংখ্যা = +1 এবং O এর জারণ সংখ্যা = -2
শর্তমতে, (+1) × 2 + x + (-2) × 4 = 0
বা, 2 + x - 8 = 0
বা, x - 6 = 0
বা, x = +6
সুতরাং, H2SO4 যৌগে S এর জারণ সংখ্যা +6।
২. CuSO4 যৌগে Cu এর জারণ সংখ্যা নির্ণয়:
সমাধান:
ধরি, Cu এর জারণ সংখ্যা = x
যৌগমূলক সালফেট (SO4) এর জারণ সংখ্যা = -2
শর্তমতে, x + (-2) = 0
বা, x - 2 = 0
বা, x = +2
সুতরাং, CuSO4 যৌগে Cu এর জারণ সংখ্যা +2।
৩. KMnO4 যৌগে Mn এর জারণ সংখ্যা নির্ণয়:
সমাধান:
ধরি, Mn এর জারণ সংখ্যা = x
K এর জারণ সংখ্যা = +1, O এর জারণ সংখ্যা = -2
শর্তমতে, (+1) + x + (-2) × 4 = 0
বা, 1 + x - 8 = 0
বা, x - 7 = 0
বা, x = +7
সুতরাং, KMnO4 যৌগে Mn এর জারণ সংখ্যা +7।

টপিক ২: একমুখী ও উভয়মুখী বিক্রিয়া

চুনাপাথরকে (CaCO3) খোলা পাত্রে ও বদ্ধ পাত্রে তাপ দিলে ভিন্ন ভিন্ন বিক্রিয়া ঘটে। নিচে অনুধাবনটি দেওয়া হলো:

অনুধাবনমূলক প্রশ্ন: একমুখী বিক্রিয়া কি?ব্যাখ্যা কর।
বিক্রিয়া: CaCO3 (s) → CaO (s) + CO2 ↑
ব্যাখ্যা: CaCO3 কে খোলা পাত্রে তাপ দিলে সেটি ভেঙে CaO (চুন) ও CO2 (গ্যাস) উৎপন্ন হয়। পাত্র খোলা হওয়ায় CO2 গ্যাসটি উড়ে যাবে এবং পুনরায় বিক্রিয়া করে CaCO3 এ পরিণত হতে পারবে না। এভাবেই খোলা পাত্রে তাপ প্রদানে একমুখী বিক্রিয়া সংঘটিত হয়।
অনুধাবনমূলক প্রশ্ন: উভয়মুখী বিক্রিয়া কি?ব্যাখ্যা কর।
বিক্রিয়া: CaCO3 (s) ⇌ CaO (s) + CO2 (g)
ব্যাখ্যা: CaCO3 কে বদ্ধ পাত্রে তাপ দিলে এটি ভেঙে CaO ও CO2 গ্যাস উৎপন্ন করে। কিন্তু পাত্রটি বদ্ধ থাকায় CO2 উড়ে যেতে পারে না। ফলে উৎপন্ন CaO এবং CO2 পুনরায় একে অপরের সাথে বিক্রিয়া করে CaCO3 তৈরি করে। অর্থাৎ, বিক্রিয়াটি সম্মুখ ও পশ্চাৎ উভয় দিকেই ঘটে। তাই এটি একটি উভয়মুখী বিক্রিয়া।

টপিক ৩: তাপোৎপাদী ও তাপহারী বিক্রিয়া

তাপোৎপাদী বিক্রিয়া (Exothermic Reaction):

সংজ্ঞা: যে রাসায়নিক বিক্রিয়ায় তাপ উৎপন্ন হয়, তাকে তাপোৎপাদী বিক্রিয়া বলে।

বিক্রিয়া চেনার উপায়:
  • A2 + B2 → 2AB + তাপ
  • A2 + B2 → 2AB ; ΔH = -তাপ (ঋণাত্মক)
উদাহরণ: C + O2 → CO2 + 393.5 kJ
(বা, C + O2 → CO2 ; ΔH = -393.5 kJ/mol)
শর্টকাট: উৎপাদের সাথে তাপ যোগ থাকবে অথবা ΔH এর মান ঋনাত্মক হবে।
তাপহারী বিক্রিয়া (Endothermic Reaction):

সংজ্ঞা: যে রাসায়নিক বিক্রিয়ায় তাপ শোষিত হয় (অর্থাৎ তাপের প্রয়োজন হয়), তাকে তাপহারী বিক্রিয়া বলে।

বিক্রিয়া চেনার উপায়:
  • A2 + B2 + তাপ → 2AB (বা, A2 + B2 → 2AB - তাপ)
  • A2 + B2 → 2AB ; ΔH = +তাপ (ধনাত্মক)
উদাহরণ: N2 + O2 + 180 kJ → 2NO
(বা, N2 + O2 → 2NO ; ΔH = +180 kJ/mol)
শর্টকাট: বিক্রিয়কের সাথে তাপ যোগ থাকবে অথবা ΔH এর মান ধনাত্মক হবে।
